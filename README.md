---

## Overview

This task presents the analytical findings through interactive Tableau dashboards. The dashboards communicate technical, predictive and business insights derived from the HMDA mortgage dataset using visual analytics and data storytelling.

---

## Objectives

- Develop interactive dashboards
- Present business insights
- Compare machine learning models
- Demonstrate pipeline monitoring
- Visualise scalability metrics

---

## Tableau Dashboards

### Dashboard 1
**Data Quality & Pipeline Monitoring**

Visualises data quality assessment, preprocessing workflow, feature engineering summary and pipeline execution.

### Dashboard 2
**Model Performance & Feature Importance**

Compares machine learning models using Accuracy, Precision, Recall, F1-Score, ROC-AUC, prediction runtime and SHAP feature importance.

### Dashboard 3
**Business Insights**

Analyses mortgage approval trends by state, income band, loan purpose, applicant race and applicant ethnicity.

### Dashboard 4
**Scalability & Cost Analysis**

Evaluates cache performance, partition optimisation, Spark runtime and distributed resource utilisation.
