# HMDA Mortgage Loan Approval Prediction using PySpark

## Overview

Module: 7006SCN Machine Learning and Big Data · Coventry University

Module Leaders: Dr Katerina Stamou · Miss Eziamaka Nwakile

Repository: 7006SCN2526MAYJUL/7006SCN_vlb_16859171

The objective is to develop a scalable machine learning solution capable of predicting mortgage loan approval decisions using the **2023 HMDA Mortgage Application Register**.

Apache Spark and PySpark were used for distributed data engineering, machine learning and performance optimisation, while Tableau was used for business intelligence and interactive dashboard development.

---

## Dataset

- HMDA 2023 One Year National Loan Level Dataset
- Source: Consumer Financial Protection Bureau (CFPB)
- URL: https://ffiec.cfpb.gov/data-publication/one-year-national-loan-level-dataset/2023
- Records: 11.5+ Million
- Features: 80+
- Size: >1 GB
